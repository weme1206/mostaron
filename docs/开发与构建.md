# 开发与构建

## 环境要求
- [Flutter SDK](https://docs.flutter.dev/get-started/install)（3.13+，本工程用 Flutter 3.35 / Dart 3.13）
- Android SDK（compileSdk 36，build-tools 34/35/36，platforms android-34/35/36）
- JDK 17（Temurin）

## 获取依赖
```bash
flutter pub get
```

## 构建（Release APK）
```bash
flutter build apk --release
```
产物：`build/app/outputs/flutter-apk/app-release.apk`

> 构建会生成/复用签名。本项目默认读取 `android/key.properties` 中的签名配置。

## 签名
Release 签名在 `android/app/build.gradle.kts` 中读取 `android/key.properties`：
```
storeFile=release-key.jks
storePassword=xxxx
keyAlias=release
keyPassword=xxxx
```
- **`release-key.jks` 与 `key.properties` 已被 `.gitignore` 忽略，请勿提交到公开仓库。**
- 如需换密钥，用 `keytool` 生成：
```bash
keytool -genkeypair -v -keystore release-key.jks -alias release -keyalg RSA -keysize 2048 -validity 10000 \
  -dname "CN=Your Name, OU=Dev, O=Org, L=City, ST=State, C=CN"
```

## 应用图标
- 源图：`assets/icon/icon.png` 与 `assets/icon/icon_fg.png`。
- 重新生成 Android 图标：
```bash
flutter pub run flutter_launcher_icons
```

## 国内网络提示
- 依赖下载源可通过 `FLUTTER_STORAGE_BASE_URL` 覆盖，如：
```bash
export FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn
```
- 若 Gradle 主站不可达，可将 `android/gradle/wrapper/gradle-wrapper.properties` 的 `distributionUrl` 改为镜像（如 `mirrors.cloud.tencent.com/gradle`）。

## 隐私与数据
- 全部数据存于本地 SQLite（`getDatabasesPath()/mostaron.db`）。
- App 联网仅为调用你配置的接口，不持有服务器。
- 导入为合并模式，不覆盖已有数据。
