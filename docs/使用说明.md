# 使用说明

本指南按模块介绍 mostaron 的功能与操作。

## 1. 接口与模型
- 进入 **设置 → 接口**（或主页右上角 ＋ → 模型设置）。
- 点 **添加接口**：填写名称、**Base URL**、**API Key**、模型名。
  - 可点上方**快速预设**（OpenAI / DeepSeek / Kimi / 智谱 GLM / 千问 / Ollama 等）一键填充 Base URL 与模型名。
  - **获取模型**：自动拉取该 Key 可用模型，**带搜索、可多选**，确定后加入该接口分组。
  - **测试连接**：验证接口可用性。
- **多点一个接口行**进入**模型分组**，查看该接口下所有模型，可**继续添加 / 删除**，用单选**设默认模型**。
- 聊天输入框左侧 **模型按钮**：单聊/群聊都可切换模型（点接口 → 点分组内模型）。

## 2. 角色
- 主页角色/群聊卡片**名称下方显示该角色/群聊的最新一条消息**（角色或用户发的都可以）。
- 主页右上角 **＋ → 添加角色**，或长按已有角色 → **编辑 / 克隆 / 重置 / 置顶 / 创建群聊 / 删除**。
- 新建/编辑角色：
  - **头像**：预设颜色 / 上传图片（进入**裁剪页**，单指拖动、双指缩放，圆内即头像）。
  - 人设、性格、语气、背景故事、开场白、**自定义聊天背景**（上传图片）。
  - **用文字快速生成角色**：输入一句描述，AI 生成角色（含开场白），点 **撤销** 可还原。
  - **回复风格**：默认 / **简短对话**。
  - **独立模型 / Key**：为这个角色单独选接口与模型。
  - **选择世界书**：从全局世界书里勾选这个角色要启用的条目。
  - **角色设置**（底部展开）：独立上下文轮数、记忆注入、感应现实、记忆上限等，默认沿用主设置。

## 3. 聊天
- 发送消息 → 角色**流式**回复。输入框 **回车换行**，点发送键发送。
- 支持 `（动作）` 与台词混合渲染（动作斜体），兼容 `*动作*` / `(动作)`。
- 最新一轮消息下方按钮：
  - 角色消息：**重新生成 / 删除 / 编辑 / 生成我的回复**。
  - 我的消息：**删除 / 编辑 / AI 改写**。
- **顶部菜单**（右上角）：角色设置、聊天窗口设置（显示头像/上下文）、长期记忆、选择世界书、删除当前对话。
- 开启"输出思考"时，思考内容以 **「思考 ›」** 小折叠显示在消息上方，点开查看。

## 4. 群聊
- 主页右上角 **＋ → 创建群聊**（或长按角色 → 创建群聊，自动带入该角色）。
- 编辑群聊：群名、头像、**背景**、成员（**拉人/踢人**，删除需确认）、回复模式、回复风格、你的身份（名字/性别/身份背景）、选择世界书。
- **回复模式**：
  - **全员回复**：每个人回复一条，用户提到的角色优先。
  - **指定发言**：输入框上方出现成员胶囊，点谁谁回（可重复点同一角色）。
  - **自然聊天**：AI 判断是否回复，**轮流**，**至少一人**回复，可设每角色最多回复条数（建议 1，过高易刷屏）。
- 群聊也可：切换模型、长记忆、世界书、聊天窗口设置（隐藏角色头像会提示"无法区分角色"）、隐藏我的头像。

## 5. 长期记忆
- 聊天页 → 顶部菜单 → **长期记忆**。
- 手动**添加/删除**，**置顶**的记忆会写入 **AGENTS.md** 长期生效。
- 置顶 + 最近记忆都会注入系统提示。
- **AI 生成记忆**（顶栏按钮）：从当前对话提炼记忆并保存。
- 开启记忆后，会**按设定的间隔（默认每 6 条）自动**生成一条记忆；主设置/角色/群聊设置都可改间隔（角色/群聊优先，创建默认用主设置值）。
- 设置里可开启"**感应现实**"（让角色知道当前日期时间）、"**记忆达上限自动删除**"（可设上限）。
- 置顶的记忆在记忆列表里以**颜色加深**标示。
- **查找聊天记录**：聊天/群聊右上角菜单 → 查找聊天记录，输入关键词即可找到并点击跳转到对应消息。

## 6. 世界书（全局 + 按角色/群勾选）
- **全局管理**：进入 **设置 → 世界书**，可**新增 / 编辑 / 删除**世界书条目。
- 每条目：名称、**关键词**（逗号分隔）、触发时注入的背景内容、启用开关。
- 为**某个角色/群聊**启用：在**角色编辑**或**群聊编辑**里点「选择世界书」，从全局条目里**勾选**要启用的（默认全不启用）；也可点「管理全局世界书」直接跳到全局管理。
- 聊天中命中关键词会将对应条目内容作为背景注入，增强沉浸。

## 7. 外观与主题
- **设置 → 外观**：
  - **主题色**：预设几种主题色（无调色盘）。
  - 亮/暗/**跟随系统**、**夜间自动切暗色**（可设开始/结束时间）。
  - **自定义主题背景**：上传图片，**只影响主页**背景。
- **角色/群聊聊天背景**：在**角色编辑**或**群聊编辑**里单独上传，只影响对应聊天窗口；与主设置的主题背景互相独立。
- **设置 → 聊天气泡**：可分别设置**我的/角色**气泡颜色（白/橙/粉/紫/深蓝/绿/红/黑 + 调色盘可选）与**透明度（0–100%，每 1% 可调）**；点"默认"删除恢复。
- **角色/群聊的头像显示**：不在主设置，而在**角色/群聊的聊天窗口设置**里单独开关（默认开启）。

> 说明：主题背景只作用于主页，不影响角色/群聊的聊天窗口背景；聊天窗口背景请在其编辑里单独设置。

## 8. 数据
- **设置 → 数据**：**导出全部数据** / **导入全部数据**。
- 导入为**合并模式**：新增而不覆盖已有的角色、接口、世界书、聊天。
- 全部数据存于本地 SQLite，不上传。

## 9. 个性化
- **设置 → 你的身份**：名字、性别、与角色的关系、你的身份背景。
- 这些作为创建角色/群聊时"你的身份"的默认值；每个角色/群聊也可以单独改。

## 快捷提示
- 主页返回会弹出"确定退出吗"。
- 消息**长按**可复制 / 删除。
